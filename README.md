## kERBEROS AUTHENTICATON USING ACTIVE DIRECTORY ##  
## Overview ##
This project shows the analysis of kerberos authentication in active directory .it shows how the  Key Distribution Center (KDC), Authentication Server (AS),Ticket granting Server (TGS) works in active directory.

Kerberos is a secure network authentication protocol that uses a centralized Key Distribution Center (KDC) to authenticate users and services. KDC is the heart of the keberos that supplies ticket and generate temporary temporary session key that allow a user to securely authenticate into a service .it consist of two main component:  
* AUthentication Server (AS)
* Ticket granting Server (TGS) 
## Tool used ##
 Active directory is used to analyse keberos authentication which is  centralized identity management system used by adminsistrators to manage users, computers and other resources on a network.
